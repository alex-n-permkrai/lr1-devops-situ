## Описание

Скрипт обращается к бесплатному API [wttr.in](https://github.com/chubin/wttr.in), получает данные о погоде в формате JSON и извлекает:

-  температуру (°C)
-  влажность (%)
-  ощущается как (°C)
-  текстовое описание погоды

Затем он **дописывает новую строку** в HTML‑таблицу, расположенную по умолчанию в `/var/www/html/index.html`. Если файла не существует, скрипт создаёт его с красивой стилизованной таблицей. Используется атомарная замена через временный файл.

## Как это работает

1. Вы передаёте городу аргументом командной строки (например, `Perm`).
2. Скрипт кодирует название города для URL.
3. Загружает `https://wttr.in/ваш_город?format=j1`.
4. Парсит JSON с помощью `jq`.
5. Добавляет новую строку в таблицу HTML‑файла.
6. Если файла нетб то создаёт его с базовой стилизацией.
7. Выводит сообщение в консоль о добавлении записи.

**Ключевые особенности:**
- Постепенное накопление записей – журнал погоды растёт со временем.
- Безопасная вставка в HTML (экранирование специальных символов).
- Атомарное обновление – файл не повреждается при сбое.
- Поддержка кириллицы и пробелов в названиях городов.

## Требования

- **Bash** 4.4+
- Утилиты: `curl`, `jq`, `sed`, `mktemp`, `date`
- (опционально) **Nginx** или любой другой веб‑сервер для просмотра HTML
